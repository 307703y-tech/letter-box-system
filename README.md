# 虚拟信箱系统 Letter Box System

一个创意的虚拟信箱网站，用户可以手写或输入信件，设置取信码，与他人分享信件。

## 功能特性 ✨

### 核心功能
- **📬 信箱界面** - 美观的信箱主界面
- **✍️ 书写信件** - 支持两种书写方式：
  - 📝 文字输入
  - ✏️ 手写绘画（支持鼠标和触摸）
- **🔐 取信码系统** - 用户自定义的取信码
- **📖 阅读信件** - 输入取信码查看他人信件
- **💾 本地存储** - 所有数据存储在浏览器 localStorage 中

### 信件信息
每封信件包含：
- 寄信人名字
- 收信人名字
- 信件标题
- 信件内容（文字或手写图片）
- 发送时间
- 专属取信码

## 使用方法 📖

### 书写信件
1. 点击 "书写新信件" 按钮
2. 填写寄信人名字、收信人名字和信件标题
3. 选择书写方式：
   - 切换到 "📝 文字" 标签页输入文字
   - 切换到 "✏️ 手写" 标签页进行手写绘画
4. 设置一个取信码（用于他人查看信件）
5. 点击 "📮 发送信件" 完成发送
6. 系统会显示取信码，可以分享给他人

### 阅读信件
1. 点击主界面的信箱或点击 "取信" 
2. 输入取信码
3. 点击 "查看信件" 查看详细内容

## 手写功能说明 🖊️

- **绘画工具** - 使用鼠标或触摸笔进行手写
- **撤销功能** - 可以撤销最后一次笔画
- **清除功能** - 清空整个画布重新开始
- **触摸支持** - 完全支持移动设备触摸操作

## 技术栈 🛠️

- HTML5 - 页面结构
- CSS3 - 样式和动画
- Canvas API - 手写绘画功能
- localStorage API - 本地数据存储
- 原生 JavaScript - 无依赖框架

## 隐私与安全 🔒

- 所有数据存储在浏览器本地
- 不涉及服务器，无网络传输
- 清空浏览器缓存时数据会丢失
- 建议定期导出重要信件

## 使用提示 💡

1. **取信码设置** - 取信码应该简短但易于记忆
2. **隐私保护** - 妥善保管取信码，只分享给信任的人
3. **备份建议** - 如需保存信件，可以截图或打印
4. **跨设备** - 由于使用本地存储，不同设备间数据不同步
